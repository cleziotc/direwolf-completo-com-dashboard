# Avisos e créditos

Este repositório reúne um dashboard web e scripts de instalação para uso com o Direwolf.

O **Direwolf não é redistribuído neste repositório**. Os instaladores obtêm o código-fonte diretamente do projeto oficial `wb2osz/direwolf` e o compilam no equipamento do usuário. O Direwolf possui seu próprio licenciamento e seus próprios autores.

O dashboard foi desenvolvido a partir de uma estação APRS real, por **Clézio da Cunha Costa (PP5CI)**, com apoio do ChatGPT/OpenAI no desenvolvimento, documentação e testes.

Antes de transmitir em RF, confirme sua licença, legislação local, plano de banda, frequência, potência, identificação e regras aplicáveis a iGate/digipeater. A instalação padrão mantém TX desabilitado até que o usuário o habilite explicitamente.
